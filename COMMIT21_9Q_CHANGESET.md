# Commit 21 — 9Q Deep Quality + Q10 Safety

## Base
Commit 20.2.1 Stability Fix.

Commit 21 is a **quality-path overlay**, not a runtime rewrite. The existing 20.2.1 boot chain, memory governor, request governor, Saved Signals Multi-Activo fix and bounded PPE route count remain the base.

## Central architectural change
The former quality concept was too coupled to execution Safety. Commit 21 separates them:

- **Q1–Q9:** deep quality assessment of an already selected directional thesis and its execution package.
- **Q10:** the existing Safety / Premium publication contract, unchanged and hard.

The nine dimensions are:

| Quality | Meaning | Main sources already present in the system |
|---|---|---|
| Q1 | Thesis / directional coherence | traders, Operational Intelligence, thesis, trend/momentum/structure |
| Q2 | Structure / Smart Money | Smart Money, SMC, sweep, MSS/BOS, displacement, OB/FVG, invalidation |
| Q3 | Multi-Timeframe | Multiframe trader, governed MTF profiles, unique TF snapshots |
| Q4 | Strategy / family fit | Strategy Bank, contingency engine, Operational Intelligence, family/regime/volatility compatibility |
| Q5 | Flow / derivatives | Whale, volume, OI, funding, liquidation, order-book, Greeks/options, sentiment, correlation when already available |
| Q6 | Entry quality / reachability | Entry committee, POI/value/liquidity candidates, reachability |
| Q7 | Exit / economic geometry | SL, TP and execution geometry committees, R/R, target reachability and reaction risk |
| Q8 | Regime / timing / volatility / macro | regime, ATR/volatility, session, macro and timing context |
| Q9 | Statistical / evidence authority | exact-cell Champion/Research evidence, OOS/WF state, alpha-decay state |
| Q10 | Safety / publication | existing Safety/TP/SL/RR/loss-at-SL/ATR-stress hard contract |

## Runtime guarantees
- No new worker.
- No new thread.
- No new network request.
- No live-outcome fitting.
- No direction creation.
- No Entry/SL/TP invention by Q1–Q9.
- Maximum two alternative routes, inherited from the stable 20.2.1 geometry contract.
- Route selection changes only the ranking among geometries already generated by the native execution method.

## Publication rule
Q1–Q9 cannot override Q10. A high 9Q score cannot turn a candidate into Premium when the existing hard publication contract fails.

The contract remains:

- Safety >= 75
- TP quality >= 55
- SL quality >= 60
- 1.8 <= R/R <= 3.5
- Existing loss-at-SL and ATR-stress checks

The 9Q layer may select a different already-generated route that produces a stronger quality package. It never lowers the Q10 limits.

## Evidence policy
Q9 is scoped to the exact strategy evidence available for the current cell. Evidence from another symbol is not silently converted into a local Champion. GROUP_PRIOR/Research evidence may be diagnostic but cannot manufacture LIVE_CHAMPION authority.
